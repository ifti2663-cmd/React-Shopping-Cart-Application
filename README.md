# Luma Shopping Cart

A responsive React storefront and shopping cart built for the Module 20 assignment.

## Features

- Product catalog with category filters
- Add-to-cart, quantity controls, and item removal
- Live item count and subtotal
- Shared cart state with React Context
- Cart persistence with local storage
- Responsive layouts for mobile and desktop

## Run locally

```bash
npm install
npm run dev
```

Create a production bundle with:

```bash
npm run build
```
